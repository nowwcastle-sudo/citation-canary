# Code of conduct

People working on this project are expected to be respectful, direct,
and considerate. Discuss evidence and code, not a person's identity. Do not
share HWPX contents, catalog data, credentials, personal information, or
customer materials. Report harassment or unsafe behavior privately to the
repository owner using an existing private contact. If none is available,
request a private contact in an issue without identifying anyone or disclosing
incident details. Participation may be paused when these boundaries are
violated.
